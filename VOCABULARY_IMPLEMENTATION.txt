### 🔄 How It Works:

```
User Opens Settings
    ↓
useEffect loads vocabulary from Supabase
    ↓
Display vocabulary list with add form
    ↓
User adds term → Saved to Supabase
    ↓
Backend fetches vocabulary when formatting
    ↓
DeepSeek gets enhanced prompt with user vocabulary
    ↓
Better speech-to-text results!
```

### 📝 Database Requirements:

Ensure Supabase has `user_vocabulary` table with:
```
- id (UUID, primary key)
- user_id (UUID, foreign key to auth.users)
- term (text)
- pronunciation (text, nullable)
- context (text, nullable)
- created_at (timestamp)
- updated_at (timestamp)
```
